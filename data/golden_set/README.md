# Разметка бабочек команды 10

Проверенная версия от 20 ноября 2026 года содержит 415 фотографий iNaturalist с лицензией CC0. На 373 снимках размечена хотя бы одна взрослая бабочка, ещё на 42 подтверждено отсутствие взрослых бабочек. Всего сохранено 448 рамок.

| Файл | Для чего нужен |
|---|---|
| [golden_set.jsonl](golden_set.jsonl) | Эталонные нормализованные рамки по каждому из 415 ID |
| [manifest.jsonl](manifest.jsonl) | Те же ID, ссылки на оригиналы и наблюдения, происхождение и лицензии |
| [evidence/decision_log.jsonl](evidence/decision_log.jsonl) | История отбора всех 454 ID командного списка. Содержит исходные варианты, сводку ревью, индивидуальные ответы троих для 87 спорных случаев и обоснование итоговой геометрии |
| [evidence/crowd/](evidence/crowd/) | Обезличенные выгрузки исходных ответов и описание их обработки |

## Как оценивать

Соединяйте манифест и эталон по числовому полю `photo_id`. Вход модели — изображение по адресу `photo_url`. Поле `category` служит для анализа качества по сценариям. В эталоне `left`, `top`, `width` и `height` отсчитываются в долях ширины и высоты изображения. Пустой список `boxes` означает подтверждённое отсутствие объекта.

Рамка охватывает видимые части одной взрослой бабочки, включая дневных и ночных. Разные особи получают отдельные рамки. Гусеницы, куколки и другие насекомые не входят в целевой класс.

## Охват версии

Из 454 уникальных ID в исходных таблицах команды пять фото имели лицензию CC BY, а одно побайтно совпадало с другим фото. Из 448 оставшихся CC0-снимков 415 имеют статус `ready`, остальные 33 — `pending_human_review`. У 31 пустого кадра пока есть только результат просмотра моделью, у одного кадра с рамкой отсутствует вердикт независимого ревьюера, у одного фото изменились финальные координаты после проверки троими. Эти снимки сохранены в журнале. Для финального сравнения моделей на полном командном наборе после ревью обновите эталон и манифест вместе и прогоните одну и ту же версию через все три модели.

Расхождения троих разобраны по фотографиям. Предложения и визуальные решения Codex отмечены отдельно. В авторстве сохранена строка атрибуции iNaturalist и, где заполнено, имя автора из командного манифеста. У каждой фотографии есть ссылка на её страницу в iNaturalist.
