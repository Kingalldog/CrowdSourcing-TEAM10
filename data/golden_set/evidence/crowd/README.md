# Ответы Яндекс Заданий

Одна строка JSONL соответствует одному принятому ответу исполнителя на отдельное фото. Файлы охватывают ID из исходного командного списка из 454 фотографий. Какие из них вошли в golden set, указано в журнале итоговых решений.

| Файл | Строк | Что сохранено |
|---|---:|---|
| `bbox_responses.jsonl` | 471 | 447 исходных ответов основного пула (357 обычных, 90 контрольных), ещё 24 обычных из пилота. Всего 414 разных фото. Для каждой строки сохранены рамки, поля отсутствия объекта и ошибки загрузки. |
| `review_responses.jsonl` | 1 369 | 1 242 вердикта по обычным карточкам, 127 по контрольным. Включены 413 фото и 421 вариант разметки. |
| `review_excluded.jsonl` | 15 | Вердикты по пяти первоначальным карточкам с повреждённым представлением рамок. По три ответа на обычную карточку. Эти строки исключены из итоговых голосов. |

Для основного Bbox, пилота и Review взята последняя доступная выгрузка каждого пула от 19 ноября 2026 года. Предыдущие снимки тех же пулов не суммировались. В основной выгрузке Bbox 45 строк с пустым статусом, в Review 127. В расчёт вошли только записи со статусом `APPROVED`. Из 30 ответов пилота шесть относились к пяти фото вне списка команды и были пропущены.

`photo_id` — публичный идентификатор iNaturalist. Общий ключ `candidate` связывает ответ Bbox, его координаты и вердикты Review. Одинаковые рамки в разном порядке у одного фото получают одинаковый ключ. Ключ составлен из первых 20 шестнадцатеричных знаков SHA-256. Входом служит UTF-8 компактного JSON `[photo_id, координаты]`, где каждая рамка — массив чисел Python float в порядке `left, top, width, height`, массивы отсортированы лексикографически. Например, в Python используется `json.dumps(payload, separators=(",", ":"))`. Координаты в строке Bbox сохранены в исходном порядке. Поля `reference_*` — проверочные ключи платформы.

`reviewer_within_candidate` — порядковый номер проверяющего внутри одного фото, варианта рамок и роли карточки. Для каждого нового сочетания нумерация начинается заново. Номер позволяет проверить подсчёт повторных голосов внутри одной группы. Если тот же человек повторил тот же вердикт для тех же рамок в той же роли, в счёт идёт одно наблюдение. Для семи повторных ответов выставлено `counts_in_tally: false`. Из 1 369 корректно выданных ответов учтены 1 362. По исходным выгрузкам проверено, что каждый автор Bbox и проверяющий его карточки различаются.

Пять повреждённых версий относились к фото 699914361, 704459801, 714949732, 738390305 и 758722072. Для них сериализованные строки заменили объекты рамок на входе Review. В отдельном файле `corrected_candidate` указывает, какую геометрию показали в исправленной выдаче. Вердикты исправленных карточек входят в основной файл Review. Пятнадцать ответов из предыдущей выдачи сохраняются только для истории.

Суммы исходных ответов и учтённых вердиктов сверены с каждым вариантом рамок в журнале итоговых решений. Из 415 снимков готовой версии 406 представлены в исходных ответах Bbox и Review. Ещё 9 снимков вне пула проверили три участника команды. Их индивидуальные решения и геометрия записаны в журнале.
