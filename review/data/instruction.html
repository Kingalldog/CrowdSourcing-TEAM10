Проверьте чужую разметку

Осмотрите весь кадр, в том числе края и фон. Если изображение не открылось, выберите «Фотография не загрузилась». Если объект невозможно уверенно определить, выберите «Нужен разбор».

У каждой взрослой бабочки должна быть одна рамка. Рамка плотно охватывает видимые крылья, тело, усики и лапки. При перекрытии и обрезке учитывайте только видимую часть. Моли, другие насекомые, гусеницы, куколки и тени не обводятся.

Если есть ошибки, выберите первую подходящую причину в таком порядке: пропущена бабочка → лишняя рамка → неточная граница. Обвели сразу двух одной рамкой — «Пропущена бабочка». Если один объект отмечен дважды, в том числе при правильных границах, — «Лишняя рамка».

Выберите «Верно», если все бабочки обведены правильно или если кадр без бабочек оставлен без рамок. Небольшой отступ в несколько пикселей допустим. Не меняйте масштаб страницы для оценки точности по пикселям.

Примеры

  • пропущена бабочка

  • лишняя рамка
  • неточная граница
